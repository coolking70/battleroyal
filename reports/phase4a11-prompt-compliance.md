# Phase 4A-1.1 Prompt Compliance

- Render Style v2 is content-free and contains rendering language only.
- Category policies are isolated: character sheets are character-only; zones are environment-only; items are isolated objects; events are illustration-only.
- Scout hard constraints include adult age, binoculars-only equipment, and weapon-free hands/back/shoulders.
- School hard constraints include environment-only, zero humans/people/characters/silhouettes, and a calm open lower center.
- Bandage hard constraints include exactly one centered object, neutral backdrop, and no scenery/character/hand/interface.
- Blackout hard constraints include zero people/weapons/rain, powerless normal lights, dark displays, and sparse red emergency lamps.
- All four v2 hashes differ from their v1 hashes and generated with `cacheHits=0`.
- Prompt order places Render Style, Category Style, Entity Brief, Variant, hard constraints, and AVOID at the required boundaries.

These are structural prompt and pipeline checks only; they are not a human visual approval.
