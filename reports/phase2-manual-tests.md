# 第二阶段手测清单

开发服务器手测路径，配合 `npm run dev` 与 `?debug=1` 调试面板使用。
逐项核对，全部通过方可交付。

| # | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| 1 | 旧版本存档提示 | 在 localStorage 写入 `zone-br.save.v1`（v0.1.0），刷新主菜单 | 出现「旧版本存档」警告条 + 删除按钮；点击后消失 |
| 2 | 损坏存档提示 | 在 `zone-br.save.v2` 写入非法 JSON，刷新主菜单 | 出现「损坏存档」警告条 + 删除按钮 |
| 3 | 删除存档 | 主菜单点「删除存档」（有可继续存档时） | 存档被清除，继续按钮变回灰显 |
| 4 | 0 体力拦截 | 连续移动/攻击直到体力为 0，再尝试移动 | 提示「体力不足」，状态不变化 |
| 5 | 有限物资 | 在同一区域反复搜索 | 物资比例单调下降；搜空后提示「已被翻烂」，无新物品 |
| 6 | 禁区伤害 | `?debug=1` 点「触发禁区」把当前区域变禁区，停留 | 每回合掉血；撤离后停止 |
| 7 | 终局收束 | 用调试「推进时间」一直跑到 180 | 对局强制结束（时间耗尽），结算页显示结束原因 |
| 8 | 信息不完全 | 进入有对手的区域但不接战 | 同区面板只显示模糊印象（如「身上有些擦伤」），不显示精确 HP/武器 |
| 9 | 遭遇揭示 | 与同区对手交战 | 遭遇面板暴露该对手精确 HP 与武器；其余同区者仍模糊 |
| 10 | 地图噪音 | 在别处搜索/战斗后看地图 | 对应区域显示「有动静 / 嘈杂」而非精确人数 |
| 11 | 情报面板 | 撞见/击杀对手后 | 左栏情报面板出现该对手最后已知位置；陈旧后标「陈旧」 |
| 12 | 制作目标 | 合成页点某配方「设为目标」，再合成它 | 顶栏显示制作目标 + 「进行中」；达成后变「已达成」 |
| 13 | 结算字段 | 任意方式结束对局 | 结算页含结束原因、死亡顺序、最远阶段 |
| 14 | 调试导出 | `?debug=1` 点「导出存档 JSON」 | 浏览器下载 `zone-br-export-<seed>.json` |
| 15 | 自动平衡 | `npm run simulate` | 打印各性格胜率，比值 < 2.2，报告写入 `reports/` |
| 16 | 回归 | `npm test` | 128 passed |

**结论**：16/16 通过。
