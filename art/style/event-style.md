# World event style

Environmental event illustration only. No protagonist and no character-focused composition; the event phenomenon itself is always the primary visual subject. Do not add unrelated atmospheric, combat, or disaster motifs. Generate only the illustration itself, with one clear environmental motif, strong mood, readable composition, no card frame, no interface, no coordinates, no explicit gore, and no monster-like transformation of ordinary infrastructure. Devices, broadcast equipment, warning fixtures, and other event props remain allowed when they serve the event.
