# Phase 4C Candidate List

This is a proposal list only. No Phase 4C implementation is included in the
Phase 4B closure.

1. Real-device touch and safe-area validation for the planning drawer, fixed
   action rail and compact landscape encounter.
2. Screen-reader review of live announcements, result headings, combat action
   names and disabled-state explanations.
3. Human visual pass for long-session density, panel rhythm and reduced-motion
   comfort; keep any changes scoped and evidence-backed.
4. ResultScreen playthrough review across victory, defeat and draw using the
   existing asset/fallback matrix.
5. Keyboard traversal review on a real browser with assistive technology,
   including drawer return focus and no accidental DebugPanel tab order.
6. Only if separately approved: performance profiling for the stacked mobile
   shell and image fallback transitions.
